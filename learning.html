A systematic learning roadmap

Designed for engineers with software and big-data experience: build the mathematical and machine-learning foundation first, complete the NLP and language-model sequence, then go deeper into data systems, distributed systems, and reinforcement learning.

How to use this roadmap

Prioritize the core sequence

CS229 → CS224N → CS336 is the central path. Add math where needed and study systems alongside the AI sequence.

Learn by building

Complete at least one representative assignment or project for every course. Watching the lectures alone does not count as completion.

Keep each course version aligned

Use videos, notes, and assignments from the same term whenever possible. A complete public edition matters more than the newest one.

Recommended learning order

Plan for roughly 12–18 months at 8–12 hours per week. Use assignments to test out of topics you already know. GitHub links marked “community” are not official course repositories.
